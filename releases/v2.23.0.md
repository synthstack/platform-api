# v2.23.0 — 2026-10-28

## Overview

This release adds console error reports, changes task pickup, and restricts base AI agent settings for organizations without enterprise access. Agents still use base settings when they run.

## Breaking Changes

- **Base AI agent settings.** Organizations without enterprise access, and marketplace connections, can no longer view or edit base AI agent settings. Use organization-level or project-level settings instead.

## Added

- **Error reports.** Signed-in users can now report problems from the console. Reports are reviewed by platform admins and deleted after 90 days.
- **Report limits.** You can submit up to 5 reports per hour. Repeated and failed submissions count toward the limit.

## Changed

- **Task pickup.** The platform now controls how often task checks happen, reducing unnecessary requests.
