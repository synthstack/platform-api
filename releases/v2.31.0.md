# v2.31.0 — 2026-11-12

## Overview

This release adds GitLab.com support for AI agent tasks with Git access. Task publication now advances automatically when a repository is rebuilt.

## By the Numbers

- **Changes.** 73 files changed, with 4,181 added and 312 removed.
- **Testing.** 18,131 tests were completed in the reported run.
- **Coverage.** Reported line coverage was 86.63% (76,182 of 87,935 lines).

## Added

- **GitLab repositories.** AI agents can now use GitLab.com repositories with Git access, fetching upstream changes and pushing a working branch.

## Changed

- **Rebuilt repositories.** Agent tasks now advance automatically after a rebuild. If the working branch is lost, start a new execution with a new `Idempotency-Key`.

## Behind the Scenes

- **Infrastructure.** This release also includes other infrastructure and internal changes.
