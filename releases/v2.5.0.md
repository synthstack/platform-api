# v2.5.0 — 2026-09-11

## Overview

A new "member" role and a stronger architectural foundation.

## Added

- **Member role.** Members get access to selected projects within an organization.
  - Organization metrics, billing, and quotas are visible only to owners and administrators.
  - Realtime events reach a member only for their projects; subscriptions are revoked when access changes.
  - Team activity is available to owners only; a member card shows account details and administrative actions.
- **User task activity** in the profile and a **team activity overview**.
- **Execution attribution.** See which person and which execution are responsible for a result.
- **Reference access check** for the admin panel.
- **Skills packaged in a nested archive folder** are now supported.

## Changed

- **AI Assist** processes requests asynchronously and delivers results over WebSocket; improved provider failure diagnostics; a fallback model for speech recognition.
- **Single time convention:** all dates are UTC in ISO 8601.
