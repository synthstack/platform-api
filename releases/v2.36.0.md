# v2.36.0 — 2026-11-22

## Overview

This release adds direct task label lookups and makes repository mirror recovery and synchronization behave more predictably.

## By the Numbers

- **Release scale.** 217 files changed, with 22,301 lines added and 632 deleted.
- **Testing.** The release test run reported 19,232 tests, with 13 skipped; all shards were verified.

## Added

- **Task label.** Retrieve a task label by its public ID `tlb_…` with `GET /tasks/labels/{id}`. This matches direct access already available for projects and AI agents.

## Changed

- **Task mirror recovery.** After a repository mirror reset, lost mirror bindings close automatically, and a replacement binding is assigned when needed. This removes manual reconciliation for each affected task.
- **Repository mirror sync.** When you link a repository to a project, its mirror synchronizes once at that moment. Creating tasks no longer repeats forced synchronization.

- **Infrastructure.** This release also includes other infrastructure changes.
