# v2.35.0 — 2026-11-17

## Overview

Version 2.35.0 makes artifact sharing more private and adds clearer ways to find and understand artifacts, projects, and data sources. It also gives more useful signals when integrations or workers need attention.

## Breaking Changes

- **Artifact sharing links.** Old public artifact links stop working in this release. Use new share links once the new sharing page is enabled.
- **Worker health verdict.** Worker health checks no longer mark the overall status as unhealthy only because failed queue entries are waiting. Check failed queue details separately.

## By the Numbers

- **Change volume.** This release touched 123 files, added 7,735 lines, and removed 484 lines.
- **Testing.** The release test run included 19,111 tests, and all reported tests passed.
- **Line coverage.** Reported line coverage is 87.36%, with 78,028 of 89,322 lines covered.

## Added

- **Public share page.** A new SynthStack share page is added for shared artifacts, with the access token kept private. It is available only after production enablement.
- **Upload author.** Artifact records now show who uploaded an attachment. This gives a clearer record for uploaded attachments.
- **Label search.** You can now search project labels by name.
- **Artifact kind filters.** Artifact catalogs can show several artifact kinds at once, such as logs and diffs, without running each filter separately.
- **Project filters.** You can filter projects by an integration or data source.
- **Data-source registration status.** Discovered data sources now show whether each source is already registered.
- **Pending integration notice.** When an enabled integration moves to pending, owners and admins receive a notice that a manual connection test is needed.
- **Failed queue triage.** You can see how long failed queue entries have waited and why they failed. You can also review, replay, or clear them without direct queue access.

## Changed

- **Task artifact inputs.** The artifact list for a task now includes artifacts from other tasks used as inputs, so you can trace dependencies more easily.

## Behind the Scenes

- **Infrastructure.** This release also includes other infrastructure and internal changes.
