# v2.16.0 — 2026-10-14

## Overview

Adds a news and notifications API for delivering updates and terms to users, and gives administrators control over engine CLI versions per configuration.

## Added

- **News and notifications API.** Administrators can create news items of three types: regular, terms, and required. Users can retrieve unread items and confirm reading or acceptance.
- **Engine version in configuration.** Administrators can now set the CLI version for each engine configuration. The runner picks up the pinned version for each execution.
