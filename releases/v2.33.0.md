# v2.33.0 — 2026-11-16


## Overview

Version 2.33.0 adds health metrics for monitoring, sends reconnect notifications for integrations, and tightens warnings and ID checks.

## By the Numbers

- **Change size.** This release changed 87 files, with 4,175 lines added and 322 deleted.
- **Testing.** A test run included 18,706 tests and reported no errors.
- **Line coverage.** Automated line coverage measured 87.20% of the measured code.

## Added

- **Monitoring.** You can scrape worker, queue, and scheduled-task health from `GET /health/metrics` for dashboards and alerts.
- **Reconnect alerts.** Owners and admins get a notification when an integration needs reconnecting after an unresolved credential rotation.

## Changed

- **Staged artifact warnings.** Warnings for staged artifacts now track unprotected volume under `staged/`, not total volume including accepted attachments.

## Security

- **OPTIONS request checks.** Prefixed ID enforcement now applies to non-browser `OPTIONS` requests without an `Origin` header, blocking raw numeric ID bypasses.

## Fixed

- **GitLab integration tests.** A manual GitLab integration test retries once if credential rotation finishes during the test, avoiding a first-attempt failure.

## Behind the Scenes

- **Internal changes.** This release also includes other internal changes.
