# v2.0.0 — 2026-08-04

## Overview

A new platform generation built around projects and tasks, with runners, realtime updates, billing, and sign-in via SynthStack.

## Added

- **Projects** as the top-level workspace for your work.
- **Tasks** — the central entity of the platform: a per-project number, labels with a managed order, comments, an activity feed, and soft delete.
- **Executions and iterations.** A stable working branch per task, sequential iteration numbers, a recorded "taken into work" moment, and execution liveness checks.
- **Agent messages.** An agent can talk to the user while a task is running.
- **Task artifacts.** Files produced by an agent: a feed, preview, download, and filtering by the authoring agent.
- **Templates.** Task creation templates and quick inserts for the editor.
- **Project feed** "Recent runs" and sorting for execution lists.
- **Runners** for executing tasks.
- **Realtime updates** in the console.
- **Billing.**
- **Sign in with SynthStack.**

## Changed

- A single glossary of task statuses and live counters per status group.
- Increased length limits for task texts, comments, and agent messages.

## Fixed

- Delays and reordering of events in the activity feed.
- Empty data on completion events.
