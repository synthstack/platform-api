# v2.26.0 — 2026-11-06

## Overview

This release lets you connect GitHub and publish AI agent results as pull requests. It also keeps project agent counts accurate after deletions.

## Breaking Changes

- **Workflow template preview.** Send JSON when previewing workflow templates; non-JSON requests are rejected.

## Added

- **GitHub publishing.** Connect a GitHub App installation to your organization, browse branches and files, and publish AI agent results to GitHub, creating or updating pull requests.
- **Source branch publishing.** When an agent works from a source branch, its result can now be published back to that branch.

## Fixed

- **Project agent counts.** Project agent counts now stay accurate after an agent is deleted.
