# v2.27.0 — 2026-11-07

## Overview

This release makes project artifact storage visible, lets projects connect more data sources, and gives agents more context during execution.

## Breaking Changes

- **Integration limit error.** If your integration checks for the old conflict response when a project reaches its integration limit, update it to handle `PROJECT_INTEGRATION_LIMIT_EXCEEDED` with HTTP `422`.

## Added

- **Project artifact storage.** You can now see how much disk space a project’s artifacts use, including system artifacts.
- **Agent execution context.** Agents can now receive the linked issue URL and the platform API version during execution.

## Changed

- **Project integrations.** Projects now allow up to 16 data source integrations by default.

## Fixed

- **Publication history.** Repeated updates to the same pull request or external link now appear as one card. Different publication types for the same pull request remain separate.
