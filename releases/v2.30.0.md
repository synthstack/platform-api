# v2.30.0 — 2026-11-10

## Overview

This release adds a GitLab connection flow and file attachments for tasks, iterations, and comments. It also keeps access tokens out of Forgejo error messages.

## Added

- **GitLab.** You can connect GitLab.com using the platform's sign-in flow, discover projects, and browse branches and merge requests. Agent runs against GitLab repositories are not enabled in this release.
- **Attachments.** Upload files and attach them when creating tasks, iterations, or comments. For new tasks, attached files can be provided to the agent as inputs.

## Security

- **Forgejo errors.** Error messages for Forgejo connections no longer show the access token you provided.
