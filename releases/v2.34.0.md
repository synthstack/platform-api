# v2.34.0 — 2026-11-16


## Overview

This release makes API key management available to all organization members and improves integration status handling, so users can manage access and connections more clearly.

## By the Numbers

- **Change statistics.** This release includes 42 changed files, 2,078 added lines, and 245 deleted lines.
- **Testing.** The release test run completed 18,790 of 18,790 tests successfully.
- **Line coverage.** Line coverage is 87.22% across 77,300 of 88,622 measured lines.

## Added

- **Personal API keys.** Organization members, including `member`, can now create, view, and revoke their own API keys through `/account/api-keys`.

## Changed

- **Disabled integrations.** A provider error no longer overrides an integration's disabled status. If it broke while disabled, enabling it moves it to `pending` until a connection test.

## Fixed

- **Integration filters.** You can now filter the integrations list by `pending` status.

- **Internal changes.** This release also includes other internal changes.
