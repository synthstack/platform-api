# v2.22.0 — 2026-10-27

## Overview

This release adds a base runtime setting for agents and keeps the link between agent messages and tasks. It also makes slug handling and retry behavior more consistent.

## Added

- **Agent runtime.** Set a base runtime for an agent when creating or editing it. Workflows can use this value.
- **Task origin.** Tasks created from an agent message now keep a link to the original message, so you can trace where the task came from.
- **Retry timing.** Rate-limited requests now provide retry timing, so the console can show how long to wait and integrations can retry more reliably.
- **Request references.** When something goes wrong, the console can include a request reference in reports, making issues easier to trace.

## Changed

- **Organization and project slugs.** Organization and project slugs now use a consistent lowercase, hyphen-separated format, so they work with agent tasks and repositories.
