# v2.29.0 — 2026-11-09

## Overview

This release adds Gitea as a separate integration type and reduces the chance that task progress updates disappear.

## Added

- **Gitea integration.** You can now connect Gitea as its own integration type, with dedicated provider settings and events, so AI agents can use Gitea repositories.

## Fixed

- **Task progress updates.** Progress updates for long-running tasks no longer replace earlier updates that were not delivered, so they are sent in order and are less likely to disappear.
