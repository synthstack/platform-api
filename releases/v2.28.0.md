# v2.28.0 — 2026-11-09

## Overview

Version 2.28.0 adds automatic cleanup of deleted task history and clearer Tasks API field names. It also makes task branch naming more predictable and keeps repository clones within expected destinations.

## Breaking Changes

- **Tasks API field rename.** `external_issue_url` now replaces `linked_issue_url` for external issue links. Update integrations that read or send the old field.

## Changed

- **Deleted task cleanup.** Deleted tasks and their history are permanently removed after a configurable 1-hour to 1-day retention period. No restore is available.

- **Task branches.** Working and publication task branches now use public IDs under the `synthstack` root, making them easier to recognize.

## Security

- **Repository clone destinations.** For Forgejo and Gitea integrations, tasks now use the configured repository origin, so unexpected clone addresses cannot be used.
